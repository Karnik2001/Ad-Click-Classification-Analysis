# Ad-Click-Classification-Analysis

This project focuses on analyzing user interaction data and building machine learning models to predict whether a user will click on an online advertisement. The goal is to understand user behavior, identify key drivers of engagement, and develop a predictive framework that supports data-driven digital marketing decisions.

## 🚀 Project Highlights

Preprocessed user interaction and demographic data.

Conducted EDA to uncover behavior and device usage patterns.

Built and compared ML models (Logistic Regression, Random Forest, Gradient Boosting).

Evaluated results using accuracy, precision, recall, and F1 scores.

Identified high-impact features to improve targeting and click-through rates.

## Model Training

Trains multiple classification models including:

- Logistic Regression

- Random Forest

- Decision Tree

- AdaBoost

- Gradient Boosting

- Voting Classifier

- SVM

- K-Nearest Neighbors

 ## Evaluation Metrics

For every model, the notebook prints:

- Accuracy

- Classification report (Precision, Recall, F1-score)

- Confusion matrix

This helps identify the best-performing classifier.
